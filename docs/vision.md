# Vision

DriftLens aims to become the observability platform for infrastructure change.

We want to answer:

Who changed production?

Why was it changed?

Was it intentional?

What systems were affected?

What should be done next?

DriftLens creates a causality graph connecting:

- Git Commits
- CI Pipelines
- Terraform Runs
- OpenTofu Runs
- ArgoCD Events
- Flux Events
- Kubernetes Audit Logs
- OpenTelemetry Traces

The goal is to transform infrastructure drift from an alert into an explainable event.
